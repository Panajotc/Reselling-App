# Reselling App

A mobile marketplace application built with React Native and Expo.

## Features

* User authentication
* JWT-based login system
* Marketplace listings
* Listing creation and editing
* Image uploads
* Account management
* Custom React hooks
* API integration
* Form validation

## Technologies Used

* React Native
* Expo
* JavaScript
* Axios
* React Navigation
* React Context
* Yup
* JWT Authentication
